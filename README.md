A program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`, for make.fun's "The poem about permission" bounty.

## Run it

```sh
node main.ts
```

The poem (182 characters):

> I spent years polishing a key
> I was too afraid to turn.
> Then one morning I knocked —
> and the door opened from the other side,
> by a hand that had been waiting
> all along for me to ask.

Requires Node 22. No network, no dependencies. Run locally with `MAKEFUN_OUTPUT_DIR` set to write the poem elsewhere for inspection.
